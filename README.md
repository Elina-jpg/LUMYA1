# LUMYA – Cercle d'Éveil

Site **fictif** créé pour une murder party.

LUMYA, le « Cercle d'Éveil », Raphaël Solane et tous les autres personnages sont inventés. Toute ressemblance avec une organisation ou une personne réelle serait fortuite.

Il s'agit d'un site statique d'une seule page, sans cookies ni collecte de données. Les espaces réservés aux joueurs sont chiffrés et ne s'ouvrent qu'avec les codes découverts pendant la partie.
